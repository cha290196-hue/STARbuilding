使用说明
  1. 导入前时相影像；需要对比时再导入后时相。
  2. 选择「绘制轮廓」逐点标注，双击或按 Enter 完成。选择「选择编辑」后可选中轮廓并拖动顶点。
  3. 选择「智能分割」并点击目标，首次使用需要联网下载模型。结果须人工核对；每次点击创建一个轮廓。
  4. 滚轮缩放，移动画布工具用于平移；左右对照分别编辑两张影像，叠加模式要求两张影像尺寸一致并已配准。
  5. 导出二值掩膜或保存工程。工程仅包含当前选中的前后时相标注，不包含图像；恢复时须重新选择同尺寸原图。

快捷键：Enter 完成绘制、Esc 取消当前绘制、Ctrl/Cmd + Z 撤销、Delete 删除选中。
